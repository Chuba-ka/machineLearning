# Лабораторная №4 — Байесовская сеть

Отчёт: **lab04.ipynb**. Теория и разбор результатов для защиты: [DEFENSE.md](DEFENSE.md). В ноутбуке сохранены результаты выполнения, таблицы и графики. Текст и выводы — на русском языке.

Данные: Student Performance (UCI), 649 записей по португальскому языку. Файл `data/student-por.csv` включён в работу; интернет при запуске не нужен. Оригинальное описание полей: `data/student.txt`.

Источник: https://archive.ics.uci.edu/dataset/320/student+performance
Архив: https://archive.ics.uci.edu/static/public/320/student+performance.zip
DOI: https://doi.org/10.24432/C5TG7T

## Запуск

Из корня репозитория с существующим окружением:

```bash
.venv/bin/python -m jupyter nbconvert --to notebook --execute --inplace bayesian/lab04.ipynb
```

Для отдельного окружения:

```bash
python -m venv .venv
.venv/bin/python -m pip install -r bayesian/requirements.txt
```

В Jupyter выберите Python этого окружения и выполните все ячейки сверху вниз. Рабочей директорией может быть корень репозитория или `bayesian`.

## Содержание исследования

Я рассмотрел связь итоговой оценки с образованием матери, прошлыми учебными неудачами, планами высшего образования и временем занятий. В отчёте представлены подготовка данных, построение сети, оценка параметров и четыре вероятностных запроса. Отдельно я исследовал последовательное добавление наблюдений, удаление ребра и чувствительность к сглаживанию.

Визуальная часть включает распределение оценок, баланс состояний, граф сети, тепловую карту CPT, сравнение частот с моделью, обновление вероятностей, анализ подгрупп с интервалами Уилсона, последовательное добавление evidence, сравнение структур и влияние сглаживания.

Точный вывод реализован перебором 32 состояний с нормировкой; специализированная библиотека не требуется. Оценка CPT использует псевдосчётчик 1 на состояние. Проверены ацикличность, нормировка, закон полной вероятности и условная независимость после удаления ребра.

В `artifacts/` сохраняются граф сети, график evidence, CSV с CPT и результатами запросов, подготовленные данные и контрольная сумма исходного CSV. Все файлы восстанавливаются выполнением ноутбука.
