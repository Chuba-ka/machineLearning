# Лабораторная работа №1: регрессия

Решение — `lab01.ipynb`, условие — `lab01.pdf`. `sem01.ipynb` — учебный материал курса.

Используется объединённый набор **красного и белого вина** Wine Quality UCI: `winequality-red.csv` и `winequality-white.csv`. Всего 6497 исходных строк и 11 химических признаков. Добавлен признак `is_white`: 0 — красное, 1 — белое. Целевая переменная — `quality`.

После удаления полных дубликатов остаётся 5320 объектов. Train — 4256, локальный test — 1064. Совпадающие наборы признаков группируются при разбиениях. Для всех моделей используются одни пять CV-фолдов; заполнение пропусков и масштабирование обучаются внутри pipeline.

В ноутбуке представлены анализ данных, baseline, Linear Regression, Random Forest, Gradient Boosting, Extra Trees, сравнение RMSE/MAE, коэффициенты и важности признаков, анализ ошибок по quality и виду вина, выводы и сохранение модели. Выбор модели выполняется по CV RMSE.

## Запуск

Из корня репозитория:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r regression/requirements.txt
python -m ipykernel install --prefix "$VIRTUAL_ENV" --name ml-lab01 --display-name 'Python (ML lab01)'
python -m jupyterlab regression/lab01.ipynb
```

Порог RMSE < 0.70 проверяется преподавателем на скрытом тесте. Локальное качество не гарантирует тот же результат на других данных.

## Результаты

Все 12 кодовых ячеек выполнены по порядку без ошибок, таблицы и графики сохранены.

| Модель | CV RMSE | Test RMSE | Test MAE |
|---|---:|---:|---:|
| Baseline | 0.88272 | 0.86758 | 0.69423 |
| Linear Regression | 0.73550 | 0.72079 | 0.56020 |
| Random Forest | 0.69277 | 0.65959 | 0.50826 |
| Gradient Boosting | 0.70497 | 0.68567 | 0.52892 |
| Extra Trees | 0.69047 | 0.65784 | 0.50398 |

По CV выбрана Extra Trees. Разброс CV RMSE между пятью фолдами — 0.01210. Локальный порог 0.70 пройден; окончательная оценка проводится на скрытом тесте.
