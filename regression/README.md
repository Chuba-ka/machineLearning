# Лабораторная работа №1: регрессия

Решение: `lab01.ipynb`. Условие: `lab01.pdf`. Исходный семинар `sem01.ipynb` сохранён без изменений.

Выбран набор **красного вина** Wine Quality UCI. Если преподаватель выдал отдельный файл или указал белое вино, нужно согласовать входные данные до оценки результатов.

## Запуск

Из корня репозитория (рекомендуется Python 3.11 или новее):

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r regression/requirements.txt
python -m ipykernel install --prefix .venv --name ml-lab01 --display-name 'Python (ML lab01)'
python -m jupyterlab regression/lab01.ipynb
```

Выберите ядро `Python (ML lab01)` и выполните **Restart Kernel and Run All Cells**. На Windows активация окружения: `.venv\Scripts\activate`.

При первом запуске ноутбук скачивает официальный архив UCI. Если доступа к сети нет, скачайте его со страницы <https://archive.ics.uci.edu/dataset/186/wine+quality> и положите `winequality-red.csv` в `regression/data/`. Разделитель CSV — `;`. Данные после загрузки сохраняются локально.

Ноутбук печатает версии библиотек. Фиксированы случайное состояние, единое разбиение и фолды. Полные дубликаты удаляются, совпадающие признаки группируются между частями, чтобы избежать утечки. Подбор проводится только на train; test используется для финальной таблицы и описательного анализа ошибок. Лидирующая модель определяется по CV.

**Статус проверки в среде подготовки:** проверены структура JSON и синтаксис всех кодовых ячеек. Обучение пока не выполнено: в среде отсутствуют зависимости, а сетевой доступ из терминала недоступен. Выводы с конкретными метриками формируются при запуске; сохранённых результатов обучения пока нет. После запуска этот статус следует обновить по фактическим результатам. Достижение порога RMSE < 0.70 на скрытом тесте не гарантируется.
