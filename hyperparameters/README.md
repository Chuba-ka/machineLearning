# Лабораторная №3: оптимизация гиперпараметров

Решение задания из [lab03.pdf](lab03.pdf) на задаче лабораторной №2 — Titanic.
Материал для подготовки к защите: [DEFENSE.md](DEFENSE.md).

Основной файл: [lab03.ipynb](lab03.ipynb). Ноутбук содержит пояснения, выполненные ячейки,
таблицы и графики. Модель: дерево решений; метрика: F1 класса «выжил».

Данные `titanic.csv` извлечены из встроенной копии в `classification/lab_titanic.ipynb`.
Исходный источник: https://www.kaggle.com/datasets/yasserh/titanic-dataset .
Целостность проверяется по SHA256. Интернет для выполнения не требуется.

Из корня проекта:

```bash
.venv/bin/jupyter nbconvert --to notebook --execute --inplace hyperparameters/lab03.ipynb
```

Либо откройте ноутбук в Jupyter/VS Code и выполните все ячейки с окружением проекта.
Зависимости перечислены в `requirements.txt`. Ячейки поддерживают запуск из корня проекта
и из папки `hyperparameters`. Результаты сохраняются в `artifacts/`: полные результаты
обоих поисков, сравнение CV/test, оценки folds, кривые, разбиение и метаданные.

Grid и Random Search проверяют по 48 комбинаций на одинаковых пяти folds.
Финальный выбор фиксируется по CV до оценки test. Test повторяет лабораторную №2,
поэтому не является новым слепым контролем; это ограничение описано в ноутбуке.
